# 🔐 SecureNet Toolkit

A beginner-friendly cybersecurity toolkit built in Python covering **Network Security** and **Cryptography** concepts.

Built as a learning project by a 2nd-year Cybersecurity student.

---

## 🛠️ Tools Included

| Tool | Description |
|------|-------------|
| `port_scanner.py` | Scans a target IP/domain for open ports |
| `cipher_tool.py` | Encrypts & decrypts messages using Caesar and Vigenère ciphers |
| `password_checker.py` | Analyzes password strength and gives improvement tips |

---

## ⚙️ Requirements

- Python 3.x
- No external libraries needed — uses Python built-ins only!

---

## 🚀 How to Run

### Port Scanner
```bash
python port_scanner.py
```
Enter a target IP (use `127.0.0.1` to scan your own machine) and port range.

### Cipher Tool
```bash
python cipher_tool.py
```
Choose Caesar or Vigenère cipher, enter your message and key.

### Password Checker
```bash
python password_checker.py
```
Enter any password and get a strength score with tips.
